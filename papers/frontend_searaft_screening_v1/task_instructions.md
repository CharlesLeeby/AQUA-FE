三、尺寸与坐标：先通过最小接口检查
========================================

按照官方custom.py处理图像及输出尺度：

- 正确处理RGB/BGR、float范围和维度；
- 使用配置scale=-1的官方缩放逻辑；
- 正确去除padding；
- 将最终flow恢复到评价图像的原像素坐标；
- x/y两个flow分量按实际宽高比例分别恢复；
- 不因为image_size写着540×960就随意裁掉输入内容；
- 不把一个像素在不同尺度下当成相同误差。

对于输入查询点p：
p_next = p + bilinear_sample(forward_flow, p)

不使用局部仿射预测，
不把邻近关键点坐标贴上原ID，
不经过LK精化后才评价SEA-RAFT的“直接预测”。

先用恒等图像和已知平移做少量接口检查，
只用于验证加载、方向、采样和缩放，不用于调参。

显存策略：

1. 先按官方scale=-1、batch=1测试原评价尺寸。
2. 若显存不足，只允许一次统一备用方案：
   在官方缩放之前，等比例将输入最长边限制到640像素。
3. 备用方案在正式结果前锁定，
   全部正式输入使用同一最长边规则，不逐图选尺寸。
4. 使用备用方案时，B/C也在相同评价工作尺寸重新计算；
   查询点和真值相应变换，所有误差最终还原为原像素单位。
   不与旧分辨率的B/C结果直接混算。
5. 若仍不能运行，停止并报告资源阻塞，
   不继续扫描尺寸、精度模式或不同模型。

========================================
五、分别测原始预测和过滤后预测
========================================

A. 原始预测能力

对已知可见真对应，报告：
- EPE中位数、p90、p95；
- ≤1px、≤2px比例；
- 有限输出率；
- 越界/无输出比例。

S在全部原查询点上给出直接预测；
重点另报共同B失败集合及C未正确恢复的子集。

缺失输出计入覆盖损失，
不能删除困难点后只比较误差。

B. 固定检查后的可用测量

S在每个图像对上计算正反向flow。
固定门：
- 有限值；
- 原像素尺度下FB误差≤1px；
- 原图8px边界内。

FB应按：
forward(p) + backward(p + forward(p))
计算，不在错误位置采样反向flow。

不将原LK成功、局部仿射支撑、NCC或F/H通过
作为S必须满足的额外硬门。
这些可以作为诊断列，不在本轮调阈值。

C也输出相同FB/有限值/边界口径下的结果；
旧C生产过滤结果另列。
若旧缓存没有这些原始字段，就重算必要的传统预测，
不能用不同过滤条件冒充完全公平的接受比较。

SEA-RAFT原始不确定性可记录，
但演示heatmap不是已校准概率。
本轮不搜索新的不确定性阈值。

C. 正确性定义

受控可见点误差≤2原像素，记正确接受。
接受但不可见，或误差>2px，记错误接受。
真值与可见性只用于离线评价，不传给模型或过滤器。

分别给：
correct / visible B-failure count
wrong accepted / all B-failure count
correct / all accepted
invisible accepted / invisible B-failure count

不把“零错误但几乎全拒绝”自动判为胜出。
不把“接受很多但错很多”自动判为胜出。

========================================
六、受控筛选的明确通过规则
========================================

以下是用户授权的开发筛选规则，不是理论最优标准。
在查看SEA-RAFT正式结果前写入protocol.md，
结果出来后不得修改。

预先定义的困难类型：
large、illumination_blur、outside_occluded。

存在至少一个上述类型，在至少两条来源序列中，
满足以下A或B之一，并同时满足错误护栏，
才认为有值得继续检验的测量能力：

A. 相对C，对共同可见B失败点的正确恢复率
   增加至少5个百分点。

或：

B. 可用覆盖率比C降低不超过2个百分点，
   且p95对应位置误差降低至少20%。
   报告共同有效点的误差与各自完整覆盖；
   不能通过只接受容易点制造误差优势。

错误护栏：
- 接受精度至少95%；
- 错误接受/全部B失败点
  ≤ max(1%, C对应错误接受率+0.5个百分点)；
- 不可见点错误接受率≤1%。

各分组样本数必须列出。
分母为0或不足以解释的分组不能算通过。
所有类型的结果都要报告，不能只展示胜出的类型。

这些是开发数据，不能把分组通过写成泛化或显著性结论。

阶段决策：
- 原始预测与过滤后结果均无实用优势：
  NO_MEASUREMENT_ADVANTAGE，结束，不接后端。

- 原始预测有优势，但固定过滤后没有兑现：
  PREDICTION_GAIN_FILTERING_UNRESOLVED，
  保留差异，不在本轮扫阈值。

- 固定有效性条件下通过上述筛选：
  进入自然短片段。

不要求全部48对全面打败C，
但只在某一类型有优势时必须限定结论范围。
