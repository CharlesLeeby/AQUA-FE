To avoid storing about7.26GB of duplicated uncompressed pixels, a task-local
read-only Bag adapter indexes original image/IMU message positions. It applies

by header time and converted-topic connection order, exactly as a materialized
converted bag is read. No message is cropped from either full sequence. No image
enhancement or KLT/export gate is changed. A failed decoding/identity check aborts
and is retained, not silently skipped to create a favorable input.
