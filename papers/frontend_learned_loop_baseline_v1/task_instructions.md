# 用户完整任务（2026-09-14）

继续 AQUA-FE。本条为完整的新任务，先保存到任务目录，
不依赖其他聊天或上一份提示词。

用户目标：
尽快获得有解释力的整体系统结果。
停止从零设计小型逐帧网络、恢复规则和坐标精化变体。

本轮新研究范围：
水下学习式全局数据关联，包括回环检测与重定位。
这是对AQUA-FE范围的明确扩展，不冒称局部里程计改进。

本轮任务：
LEARNED UNDERWATER LOOP-CLOSURE SYSTEM BASELINE

一、唯一问题

在完全相同的KLT局部轨迹、关键帧和后端条件下，
预训练学习检索能否比传统地点检索找到更多
可几何验证的真实回环，并改善全局轨迹？

本轮是成熟组件基线，不宣称论文创新。
不训练新网络，不改变KLT观测或初始化。

旧XFeat、SEA-RAFT恢复、坐标精化的停止结论全部保留。
不重开那些协议。

项目：
[https://github.com/CharlesLeeby/AQUA-FE](https://github.com/CharlesLeeby/AQUA-FE)

建议独立目录：
papers/frontend_learned_loop_baseline_v1/

建立隔离任务分支。
不修改原工作区或旧后端，不迁移整个项目到ROS2，
不升级系统CUDA、Ceres或驱动。

VINS-Fusion原生回环：
[https://github.com/HKUST-Aerial-Robotics/VINS-Fusion](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion)

[https://github.com/AnyLoc/AnyLoc](https://github.com/AnyLoc/AnyLoc)

水下重访数据与标签说明：
[https://github.com/sealoc/sealoc](https://github.com/sealoc/sealoc)

只读取直接需要的接口和配置。
不复制整个DL-VINS-Factory工程，
不为TensorRT/ROS2部署重建环境。

优先在隔离Python环境运行检索，
向现有回环流程提供候选关键帧索引。

三、先确认任务有真实重访，不能拿短窗硬做

只定向检查现有AQUALOC、CIRS、AFRL完整序列的：
图像、IMU、标定、参考轨迹及已有重访说明。

根据完整性和真实重访事实，预先锁定最多两条完整序列，
不是原来的45秒冷启动窗口。

选择依据可以是：
数据说明、参考轨迹覆盖、真实场景重访。
不能根据学习方法是否能赢来选序列。

保留完整路径，包括回环前后，不截取最有利区间。
记录这些序列是否已用于历史开发。

不要要求大规模逐像素人工标注。
参考只用于离线评价和窗口选择说明，
不能传给在线检索或几何求解。

如果现有数据没有可确认重访：
不要伪造回环，不继续堆后端运行。
明确报告NO_REVISIT_DATA和已检查的有限清单。
可以提供SEALOC/AnyLoc水下数据的最小获取计划，
但不自动下载整个新数据集或转做无关任务。

四、保持局部VIO严格相同

使用现有原始KLT和冻结VINS局部估计。
关闭旧学习加点、恢复和坐标修正。

保存或复用同一份：

- 局部位姿；
- 关键帧图像；
- 关键帧时间；
- 可用于几何验证的地图点与观测；
- 原始里程计边。

三个回环臂共享这些输入：

B：不添加回环边。
C：传统DBoW2/BRIEF等现有检索，使用现有几何验证。
L：学习检索，使用与C相同的几何验证和位姿图优化。

B/C/L不各自重新生成不同的KLT轨迹，
不让学习回环反馈改写用于比较的局部观测流。

若现有回环所需关键帧/地图点尚未保存，
仅补必要的数据保存接口。
不得只用TUM位姿文件伪造完整回环测量。

允许在隔离副本增加候选读取接口和必要数据保存，
但不修改局部初始化、残差、权重和求解算法。

五、只选择一个固定学习检索配置

优先参考DL-VINS-Factory已提供的：
DINOv2 ViT-S/14 + K=32配套VLAD词典。

必须核对：

- 模型、层/特征类型；
- 词典维度与模型一致；
- 官方权重实际加载；
- 图像预处理和归一化；
- 词典来自哪里。

不能把ViT-L的词典直接用在ViT-S上。
不能从测试查询和结果中拟合词典后称为未适配模型。

使用现成配套配置，不扫描多个模型和词典。
先做一个最小加载/显存检查，不能随机初始化凑运行。

若配套资产确实不可用，报告确切缺失；
不在本轮训练新词典或更换第二个模型。

模型只对同一组关键帧计算一次描述子并缓存。
不逐原始帧运行，不先做部署优化。

六、检索与几何验证必须分开

学习检索只产生候选关键帧，不直接产生回环边。

C/L共享：

- 相同可检索历史关键帧；
- 相同时间邻近排除范围；
- 相同top-K候选预算；
- 相同局部对应和几何验证器；
- 相同回环边处理与位姿图设置。

检索阈值使用各方法已有默认或明确预注册的设置，
不能边看结果边调到学习方法更好。

几何验证优先复用原实现。
有可靠3D地图点时使用原3D–2D/PnP流程，
正确处理相机模型和外参。

只有2D–2D对应时：
不能把本质矩阵的单位平移当成米制平移，
不能将图像相似度或F/H通过直接变成位姿图边。

无法产生合法几何约束时，记录检索与验证层结果，
不伪造系统增益。

四自由度位姿图不能被描述为通用错误尺度修复。
基线若已经严重尺度失稳，应保留并限制该序列结论，
不以“回环没有救回坏初始化”否定或支持检索能力。

七、一次小型系统比较，禁止无界扩展

序列名单、关键帧采样、检索配置和评价合同，
在读取新学习方案结果之前落盘。

每条序列最多三次局部VIO技术重复。
每次保存的同一局部输出派生B/C/L三个全局结果。
描述子只计算一次，按数据身份复用。

两条序列最多：
6次局部VIO运行；
每份局部输出对应C/L两次位姿图处理。

能合法复用现有局部输出时减少新增运行，
明确区分运行复用与独立重复。

同时报告：

1. Recall@K等检索指标，参考是否有效；
2. 几何验证通过和拒绝的候选数；
3. 可核对的正确/错误回环及无法确认情况；
4. 全局APE与固定时间RPE；
5. 回环前后误差与局部原始轨迹；
6. 关键帧推理、检索、验证和全局优化成本。

误匹配不能只靠“优化后轨迹更平滑”判断正确。
重复纹理、位置接近但视野不重叠、时间邻近自匹配需单列。

参考来自COLMAP或其他几何重建时准确标为proxy。
没有可靠真值的字段保留Unknown，
不把自生成的回环一致性当独立正确标签。

八、直接回答学习增量，不包装结果

主要比较L/C：
是否多找到真正可用的回环？
这些新增回环是否改善轨迹，而没有新增严重误闭环？

辅助比较L/B：
学习回环相对无回环整体有什么作用？

只优于B、不优于C：
只能说明回环有作用，不支持学习特有增量。

检索提高但没有合法几何约束：
RETRIEVAL_GAIN_ONLY，不称系统改善。

出现可重复的新增正确回环和实用全局收益：
PROMISING_GLOBAL_ASSOCIATION_BASELINE，
仅表示这个学习组件值得后续研究。

没有实用增量：
NO_LEARNED_LOOP_INCREMENT。
不改阈值、换模型或换序列直到出现正例。

输入、数据或回环接口确实不具备：
报告具体阻塞与已完成层次，
不扩成新的大型环境迁移任务。

本轮不自动进入水下微调或训练风险分类器。

九、成果和论文边界

AnyLoc、VINS回环及学习式水下回环已有先例。
本轮不能将成熟组件集成写成原创算法。

本轮真正要交付：

以及同局部轨迹条件下的系统对照。

如果有效，下一轮才从实际失败案例中选一个明确问题：
例如水下外观相似但几何不可验证的误回环。
在核对已有研究后，再决定是否做水下适配或可靠度校准。

不提前编造创新点、成功概率或论文录用前景。
不把全局回环收益算入旧45秒局部正例率。
