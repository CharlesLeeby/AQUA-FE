# Figure catalog

This follow-up is a registry and cross-dataset audit, not a new image-level ablation.
No new plotted figure is required to support the primary decision; the machine-readable
tables below are the authoritative displays.

## Table 1: `window_roster.csv`

Shows one row per unique mechanism-positive window, with action counters and the two texture
definitions. Selector variants never create additional rows.

## Table 2: `formal_summary.csv`

Shows full versus native/drop/unbounded APE/RPE means and the directional status. The four
repeats are deterministic reproductions, so no confidence bars or inferential tests are shown.

## Table 3: `texture_denominator.csv`

Shows how the low-texture fraction changes under operational, repeatwise-strict, and legacy
project-promoted denominators. The sparse-base-KLT column is intentionally separate.
